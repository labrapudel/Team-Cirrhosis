# Цирроз печени → ГЦК: анализ экспрессии генов (R)

Биоинформатический пайплайн для поиска генов, изменённых при гепатоцеллюлярной карциноме (ГЦК) на фоне цирроза.
Используются два независимых датасета: **GEO GSE25097** (микрочип, платформа GPL10687) и **TCGA-LIHC** (RNA-seq).

Команда «Цирроз печени», УрФУ, ИРИТ-РТФ, 2026. Куратор: Чернышева А.Е.
Участники: Ященко Д.Н. (тимлид), Агаев Турабхан Р.О., Ляшенко М.Р.

## Результаты на текущий момент

| Показатель | GEO GSE25097 | TCGA-LIHC |
|---|---|---|
| Сравнение | опухоль vs цирроз | опухоль (371) vs норма (50) |
| Метод | limma | DESeq2 |
| Значимых DEG | 2129 (976 UP, 1153 DOWN) | 8860 (7124 UP, 1736 DOWN) |

Пересечение: 24 общих UP-гена и 55 общих DOWN-генов (79 генов). Ген TOP2A входит в общие UP-гены и в гены-хабы обеих PPI-сетей.

## Требования

- R 4.3 или новее
- RStudio или Jupyter с R-ядром (IRkernel)
- Доступ в интернет (данные скачиваются из NCBI GEO и GDC)
- Свободное место на диске: несколько ГБ для данных TCGA

## Быстрый старт

```r
source("install_packages.R")   # 1. установить пакеты (один раз)
source("config.R")             # 2. подключить пороги и пути
```

Затем запускать скрипты из папки `scripts/` по порядку номеров.

| Скрипт | Что делает | Результат |
|---|---|---|
| `01_geo` | загрузка GSE25097, нормализация, limma | `results/geo/` |
| `02_tcga` | загрузка TCGA-LIHC, DESeq2 | `results/tcga/` |
| `03_visualization` | volcano, PCA, heatmap | `results/*/figures` |
| `04_intersection` | пересечение DEG GEO и TCGA | `results/venn/` |
| `05_enrichment` | GO / KEGG (clusterProfiler) | `results/enrichment/` |
| `06_ml` | модели и валидация (планируется) | `results/ml/` |

## Ручные шаги (вне R)

PPI-сети строятся во внешних инструментах:

1. Взять список топ-500 DEG из `results/geo/` или `results/tcga/`.
2. Загрузить в **STRING** (организм Homo sapiens, минимальный балл 0,4).
3. Экспортировать сеть, импортировать в **Cytoscape**.
4. Плагином **cytoHubba** посчитать метрики Degree, MCC, Closeness, MNC, EPC.
5. Сохранить результаты в `results/string/` и `results/cytoscape/`.

## Структура репозитория

```
├── README.md
├── config.R                 пороги, параметры, пути
├── install_packages.R       установка пакетов
├── data/raw/                исходные данные (не хранятся в git)
├── data/processed/          нормализованные матрицы
├── scripts/                 скрипты анализа (01_ ... 06_)
├── results/                 таблицы и графики
│   ├── geo/  tcga/  venn/  enrichment/  ml/
│   ├── string/{geo,tcga}/
│   └── cytoscape/{geo,tcga}/
└── reports/                 отчёт и презентация
```

## Правила именования файлов

- только латиница, строчные буквы, подчёркивания, без пробелов;
- шаблон: `датасет_содержание.расширение`, например `geo_deg_results.xlsx`, `tcga_volcano.png`;
- не хранить копии вида `файл (1)`, для версий использовать git.
